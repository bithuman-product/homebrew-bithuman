The Model: Supertonic 3 by Supertone Inc., released under the BigScience Open RAIL-M License dated

The on-device voice of the bitHuman Flutter plugin does not run the original Model files. It runs one
of the two modified versions below. Each is a Derivative of the Model, and the use restrictions in
Attachment A of the LICENSE apply to it.


1. Apple (iOS and macOS): half-precision storage build - files changed by bitHuman

   Changed files: onnx/duration_predictor.onnx, onnx/text_encoder.onnx, onnx/vector_estimator.onnx,
   onnx/vocoder.onnx (named supertonic3-fp16-*.onnx in the download set).

   What was changed: every float32 weight tensor (ONNX initializer) with at least 1,024 elements whose
   values are finite and inside the float16 range is stored as float16 under a new name, and a Cast
   node to float32 is inserted that recreates the original tensor under its original name. The rest
   of each graph is unchanged and computation stays float32; the weights are rounded to float16
   precision (relative error at most 2^-11). Smaller tensors and tensors outside the float16 range
   are left as float32. Each changed file also records the change in its own ONNX metadata: the key
   "bithuman.modification" holds this description and "bithuman.source_sha256" the SHA-256 of the
   original file it was made from.

   Not changed (copied byte for byte): onnx/tts.json, onnx/unicode_indexer.json and the voice style
   files voice_styles/*.json.

   Made by: bitHuman, with the script models/_core/converse/tools/make_fp16_storage.py (bitHuman's
   models repository, commit 7281dcf3e, 2026-09-28), from the original float32 files of Supertonic 3
   (byte-identical to https://huggingface.co/supertone-oss-archive/supertonic-3).

   The files and their SHA-256 digests: LocalBrainModels.voiceAssets in lib/src/local_brain.dart.


2. Android: 8-bit integer (int8) build - files changed by the sherpa-onnx project, not by bitHuman

   Package: sherpa-onnx-supertonic-3-tts-int8-2026-05-11, published 2026-05-13 in the "tts-models"
   release of https://github.com/k2-fsa/sherpa-onnx, made by that project's scripts/supertonic
   (workflow .github/workflows/export-supertonic-3-to-int8-onnx.yaml).

   What was changed: duration_predictor, text_encoder and vector_estimator were quantized to int8
   with dynamic quantization; vocoder was quantized to int8 with static quantization, calibrated on
   data from the Model's own runs (files *.int8.onnx). The voice style JSON files were packed into
   one file, voice.bin, and unicode_indexer.json was converted to unicode_indexer.bin. tts.json was
   copied unchanged.

   bitHuman makes no further change to these files: the plugin's Android brain loads them as the
   sherpa-onnx package ships them.
