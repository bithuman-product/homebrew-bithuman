Changes. The on-device speech-to-text of the bitHuman Flutter plugin does not run the original model.
It runs a modified version made by the sherpa-onnx project (https://github.com/k2-fsa/sherpa-onnx),
published 2026-05-03 in that project's "asr-models" release as
sherpa-onnx-nemo-parakeet_tdt_transducer_110m-en-36000-int8, made by its script
scripts/nemo/fast-conformer-hybrid-transducer-ctc/run-transducer-non-streaming.sh:

  * the NeMo checkpoint was exported to ONNX as three graphs (encoder, decoder, joiner) plus a token
    list (tokens.txt); only the model's TDT transducer branch was exported, not its CTC branch;
  * the weights of the three graphs were quantized to 8-bit integers with ONNX Runtime's dynamic
    quantization (encoder.int8.onnx, decoder.int8.onnx, joiner.int8.onnx).

bitHuman makes no further change to these files.
